نبغى 207 - تشغيل الموقع

الطريقة الأسهل:
1) ثبّت Node.js LTS على الكمبيوتر.
2) افتح هذا المجلد.
3) اضغط مرتين على: تشغيل نبغى 207.bat
4) سيفتح الموقع تلقائياً على:
   http://localhost:3000

مهم:
- لا تحتاج إلى npm install لهذا الإصدار.
- لا تغلق نافذة السيرفر السوداء أثناء استخدام الموقع.
- بيانات الحسابات تُحفظ في data.json.

إذا ظهرت رسالة أن Node.js غير موجود، ثبّت Node.js LTS ثم شغّل ملف BAT مرة أخرى.


تحديث منصة نبغة 15: تم تحسين رفع الملفات الكبيرة باستخدام رفع قابل للاستكمال (TUS) مع إظهار نسبة التقدم.

إصلاح الاستمرارية لـ Back4App:
1) من Supabase Dashboard افتح SQL Editor وشغّل ملف supabase.sql كاملًا.
2) أعد نشر الملفات المعدلة على Back4App.
3) اختبر إنشاء حساب تجريبي، ثم حدّث الصفحة وتأكد من بقاء عداد التسجيلات.
4) اختبر نشر فيديو من لوحة الإدارة وانتظر رسالة «تم النشر بنجاح». يجب أن يظهر في قسم الدورات بعد إعادة فتح الموقع.
ملاحظة: عداد التسجيلات أصبح يُسجّل في Supabase. نظام تسجيل الدخول الحالي نفسه ما زال يستخدم data.json، لذلك قد تحتاج حسابات الدخول المحلية إلى ترحيل مستقل إذا كانت بيئة Back4App لا تحفظ القرص.
